# Image generation briefs

Built-in Image Gen was used for all four raster assets; no external image API credentials were used.

1. Full desktop concept: complete RUNEBLADE 16-bit SNES medieval fantasy typing game; dark forest ink, ivory pixel lettering and gold accents; header, game arena, knight, slime/mushroom word enemies, hearts, typing field and start button, full pixel keyboard, five-stage campaign rail, account and best-run controls. Native HTML text and controls in implementation.
2. Forest panorama: no text/UI/characters; ancient gnarled trees, layered teal woodland, gold sunlight, fireflies, mossy stone ground at 80% height, overgrown ruins at right; hard square pixel clusters, SNES palette, wide side-view arena.
3. Transparent sprite sheet: silver armored green-caped knight idle facing right, identical knight attacking with golden sword slash, emerald slime facing left, red mushroom facing left; four separated sprites, consistent baseline, hard square pixels, no background/labels.
4. Four-quadrant biome atlas: no text/UI/characters; equal 2x2 grid with mossy woodland ruins (top left), blue crystal cavern (top right), thorn citadel courtyard (bottom left), dragon forest keep with orange embers and distant dragon silhouette (bottom right); all side-view, flat ground at 80% height, consistent detailed 16-bit pixel art.
