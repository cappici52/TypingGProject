# Game assets

The full interface concept (`concept.png`), `public/art/forest.png`, `public/art/sprites.png` and biome atlas were generated with the built-in Image Gen tool. The image assets are copied into this project. See `asset-prompts.md` for the production briefs.

Fonts are self-hosted:
- Press Start 2P and VT323 from Google Fonts (OFL notices in public/fonts).
- Syy UDT from https://github.com/Plaenithaan/Syy-BENEATHPOEM (SIL OFL 1.1, public/fonts/OFL-Syy.txt). True pixel Thai text including combining marks.

Pixel icons are project-owned rectilinear SVG paths. Gameplay, HUD, word labels, UI text and keyboard remain semantic HTML/CSS.
