# Game assets

The full interface concept (`concept.png`), `public/art/forest.png`, `public/art/sprites.png` and biome atlas were generated with the built-in Image Gen tool. The image assets are copied into this project. See `asset-prompts.md` for the production briefs.

Fonts are self-hosted:
- Press Start 2P and VT323 from Google Fonts (OFL notices in public/fonts).
- Syy UDT from https://github.com/Plaenithaan/Syy-BENEATHPOEM (SIL OFL 1.1, public/fonts/OFL-Syy.txt). True pixel Thai text including combining marks.

Pixel icons are project-owned rectilinear SVG paths. Gameplay, HUD, word labels, UI text and keyboard remain semantic HTML/CSS.


Original soundtrack: `public/audio/whispering-woods.wav` (76.8 seconds, mono 22050 Hz PCM, seamless loop). Composed for this project with handwritten D Dorian melody, synthesized lute arpeggios, recorder, bass and quiet percussion. Reproducible source: `scripts/compose-music.py`; no third-party composition, recordings, samples, downloads or external music service. This project-owned composition and recording follow the same distribution terms as the project source.

Original effects: `public/audio/effects/*.wav` are generated by `scripts/compose-effects.py` using only Python standard-library oscillators and seeded noise. Three 110ms wood/iron typing taps, normal and guardian defeat sounds, strike, hurt and start cues use no external samples.
